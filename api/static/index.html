            How routes are computed

            What this deployment runs.

            alt_routeRouting

            Travel times come from OSRM (MLD) with a motorcycle profile tuned for Sri Lankan roads. The VROOM solver chooses a stop order that fits your shift window. Each drop includes a fixed 3-minute service time.

            hubTraffic model (ST-GAT) Experimental

            2 graph-attention layers (4 heads, hidden size 16), a 2-layer GRU and an MLP head: 5,137 parameters, built with PyTorch Geometric.

            share_locationRoad graph

            13,499 intersections and 17,236 directed road segments taken from OSRM routes across Colombo (real OpenStreetMap topology).

            datasetTraining data

            One synthetic year of hourly speeds (time-of-day curve, calendar effects and noise). Calendar inputs: weekend, long weekend, Poya day, pre-/post-Avurudu. Not yet trained on real fleet GPS data.

            swap_horizFallback

            When the traffic model service is unavailable, routing uses static OSRM road speeds.

            Right now: status unknown.

            compare_arrowsSavings baseline

            Savings compare the optimized route with driving the same stops in the order you added them, with the same 3-minute stops. They're hidden when any stop couldn't be scheduled or when there's only one stop.

            ruleLimits

            One vehicle (demo rider #99) carrying up to 100 drops. Times are planning estimates.
